# Application 6 - Text Similarity

## Aim

To compare two texts and calculate their similarity using JavaScript.

## Description

Text similarity is an NLP technique used to find how closely two pieces of text are related.

This application compares the words present in two texts and calculates a similarity percentage.

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. User enters two texts.
2. Both texts are converted to lowercase.
3. Words are extracted from both texts.
4. Common words are identified.
5. A similarity percentage is calculated.
6. The result is displayed.

## Example

### Text 1

Python is a programming language.

### Text 2

Python is a popular programming language.

### Output

Similarity: 66.67%

## Applications

Text similarity is useful for:

- Plagiarism detection
- Document comparison
- Search engines
- Duplicate detection
- NLP applications
